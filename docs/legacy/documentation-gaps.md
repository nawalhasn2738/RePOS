- Original code and sample formats were inspected; no compilation, GUI run or test execution was performed for documentation.
- Known source defects are documented, not corrected. Atomic persistence, relational migration and responsibility separation remain planned.
- No claim of Maven/Gradle, database access, customer self-service, general edit/delete, refunds, payment gateways, scanner or hardware-printer support is made.
- Original report contents, deployed behavior, real-world data provenance, fault frequency and supported runtime environments remain unverified.
- Later approved investigation should produce executable evidence and explicit decisions; it must not overwrite the preserved baseline or silently rewrite accepted functionality.
