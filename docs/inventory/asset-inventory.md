## Scope and evidence limits

This register contains one entry for each of the **90 actual files** under `legacy/`, including hidden configuration. Directories, absent dependencies, embedded fixture records and individual methods are not counted as separate assets. File paths below are exact repository-relative paths.

Text files were inspected for content, declarations, relationships and selected method behavior. Binary files were read for identity/size/signature; the bundled tools also had version resources inspected without execution. The Word report was not semantically decoded. Binary contents, licensing and runtime behavior are not certified by this inventory.

Classifications are recommendations for the future reengineered application, not permission to change the preserved baseline. **Every original asset remains preserved for functional comparison**, including files classified Replace or Needs investigation. No file is classified Obsolete solely because it belongs to an IDE or older workflow.

- **Reusable:** retain or reuse with little or no modification; this is a static assessment, not a claim of passing tests.
- **Requires modification:** retain useful behavior/data/information but correct or adapt implementation, setup or coverage.
- **Replace:** replace the implementation during later authorized reengineering; keep original comparison evidence.
- **Obsolete:** confirmed unnecessary for the reengineered application. No asset currently meets that evidence threshold.
- **Needs investigation:** relevance, content, consuming tool or suitability remains insufficiently established.

All Java entry names identify their class/interface. Module names refer to existing packages or workflow groupings, not a proposed architecture. Conditions are source/configuration observations; reasons and actions are recommendations. No builds, tests, bundled executables or packaging scripts were run.

See [inventory summary](inventory-summary.md) for calculated totals and [inventory findings](inventory-findings.md) for cross-file evidence, priorities and unresolved questions.
